#  Hilitos de Amor

¡Bienvenido al repositorio oficial del sitio web **Hilitos de Amor**! Un espacio digital lleno de ternura y puntadas mágicas dedicado a la exposición de amigurumis (muñecos de crochet).

##  Descripción del Proyecto

El sitio web está diseñado para mostrar una galería de amigurumis únicos (Ranas, Conejos, Patos, Ajolotes) con secciones detalladas sobre las herramientas y materiales necesarios para su elaboración. El objetivo es ofrecer una experiencia visual agradable y responsiva, especialmente para la comunidad creativa y coleccionista.

##  Características Principales

* **Páginas de Aterrizaje Individuales:** Cada amigurumi tiene su propia página con detalles, descripción y patrones.
* **Diseño Responsivo:** Adaptabilidad completa para móviles y tablets, asegurando la correcta visualización del contenido y las imágenes.
* **Sección Educativa:** Información sobre materiales y herramientas esenciales para el arte del amigurumi.
* **Formulario de Contacto:** Para consultas y pedidos personalizados.

##  Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos, layout (Flexbox/Grid) y responsividad.
* **Remixicon:** Iconografía utilizada en el formulario de contacto.
* **Fuentes de Google:** `Dancing Script` (títulos), `Nunito` (cuerpo), `Stack Sans Headline` (amigurumis).

##  Instalación y Uso Local

Para ejecutar el proyecto en tu máquina local, sigue estos pasos:

1.  **Clonar el Repositorio:**
    ```bash
    git clone [URL_DEL_REPOSITORIO]
    cd hilitos-de-amor
    ```
2.  **Abrir los Archivos:** Simplemente abre el archivo `index.html` en tu navegador web preferido.
